Research prototype disclaimer: The samples, Doppler reference curves, candidate IDs, and matches are simulated. Matching uses offset-adjusted RMSE, not TLE/SGP4. The demo is for validating software boundaries, not proving real satellite reception. No authentication—run on localhost only.
Architecture: Python synthetic I/Q → NumPy FFT / CA-CFAR → simple Kalman tracker → synthetic template matcher → FastAPI + WebSocket → browser. SQLite holds confirmed track observations; the RF loop never reads the database.
